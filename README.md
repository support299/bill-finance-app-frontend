# ImaxAccounting — frontend

React 19 + TypeScript + Vite SPA (TanStack Router/Query, Tailwind v4, shadcn/ui). It talks only to the Django REST API
(`VITE_API_BASE_URL`, default `http://localhost:8000/api/v1`).

```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
npm run typecheck && npm run lint && npm test
npm run build        # typecheck + production build into dist/
npm run test:e2e     # contract test against a running backend (see ../README.md)
```

Layout, API conventions, environment and deployment notes are in the [project README](../README.md).
`src/api/` is the only place that performs HTTP; pages import endpoint functions from it.
`src/routeTree.gen.ts` is generated by the TanStack Router plugin on `dev`/`build`.
